# This repository contains an ASP.NET Core MVC application developed for the IT Elective 2 (Web System and Technologies) Prefinals Examination. The application functions as an interactive, Jeopardy-style flashcard game. It displays a grid of exam questions and clicking on a specific question card triggers a 3D flip animation to reveal the correct answer.
